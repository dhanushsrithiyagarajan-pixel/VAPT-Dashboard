# Installation Guide

## Prerequisites

- VMware Workstation
- Kali Linux
- Python 3
- Flask
- Nmap
- Burp Suite Professional
- OWASP ZAP
- Metasploitable 2
- DVWA

## Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/VAPT-Lab.git
cd VAPT-Lab
```

## Create Virtual Environment

```bash
python3 -m venv venv
source venv/bin/activate
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Run Application

```bash
python3 app.py
```

Open your browser:

http://127.0.0.1:5000
