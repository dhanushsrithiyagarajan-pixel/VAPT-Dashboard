# VAPT Methodology

## Phase 1 – Lab Setup

- Configure VMware
- Start Kali Linux
- Start Metasploitable 2
- Configure DVWA

## Phase 2 – Vulnerability Assessment

- Discover hosts using Nmap
- Identify open ports
- Identify running services
- Save results as XML

## Phase 3 – Web Assessment

- Configure Burp Suite proxy
- Analyze HTTP requests
- Use OWASP ZAP for automated scanning

## Phase 4 – Risk Analysis

- Upload XML into the Flask dashboard
- Parse scan results
- Classify risks:
  - Critical
  - High
  - Medium
  - Low

## Phase 5 – Reporting

- Display scan results
- Summarize findings
- Generate report
